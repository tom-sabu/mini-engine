# Vulkan Renderer

A modern Vulkan renderer built while following the excellent  
[vkguide.dev](https://vkguide.dev) tutorial.

This project is my journey into low-level graphics programming and Vulkan API architecture.  
Every line of code was written manually to deeply understand how Vulkan works under the hood.

---

## Features

Current progress includes:

- Vulkan instance & device creation
- Swapchain setup
- Graphics pipeline creation
- Command buffers
- Synchronization primitives
- Triangle rendering
- Frame overlap system
- GPU resource management

Planned features:

- [ ] Indexed mesh rendering
- [ ] Texture loading
- [ ] Camera system
- [ ] GLTF model loading
- [ ] PBR rendering
- [ ] Compute shaders
- [ ] Shadow mapping
- [ ] GPU-driven rendering

---

## Tech Stack

- **API:** Vulkan 1.3
- **Language:** C++
- **Windowing:** GLFW
- **Build System:** CMake
- **Shaders:** GLSL
- **Graphics Debugging:** RenderDoc
- **Validation:** Vulkan Validation Layers
